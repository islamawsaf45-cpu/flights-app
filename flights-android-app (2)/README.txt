FLIGHTS - Android app (WebView wrapper)

Build the APK:
1. Install Android Studio (free): https://developer.android.com/studio
2. File > Open > choose this "flights-android" folder. Let Gradle sync.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Click "locate" in the notification: that is app-debug.apk. Copy it to your phone and install it
   (allow "install unknown apps" if asked). Or plug the phone in and press Run.

The whole site is in app/src/main/assets/index.html. Edit it and rebuild to change the app.
External links (Google Calendar, Flightradar24) open in the phone's browser or apps.
